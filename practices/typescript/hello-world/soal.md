# Hello World in TypeScript

Complete the Scaffold to print a learner profile and practice basic TypeScript types.

1. Declare `add` with two numeric parameters and a numeric return type. Return their sum.
2. Inside `main`, declare explicitly typed constants: `name` is Alex, `age` is 20, and `isLearning` is true.
3. Declare a mutable numeric `lessonsCompleted` starting at zero, then reassign it using `add` to increase it by one.
4. Declare `greeting` as Keep practicing! and `sum` as the result of adding 2 and 3. Allow TypeScript to infer their types.

Keep the provided logging statements and `main()` call. Running the completed file must print:

```text
Hello, world!
Name: Alex
Age: 20
Learning TypeScript: true
Lessons completed: 1
2 + 3 = 5
Keep practicing!
```
